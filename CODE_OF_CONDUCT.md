# Code of Conduct

This project is intended to be a professional, practical space for building and improving agent systems.

## Expected Behavior

- Be direct, respectful, and constructive.
- Assume contributors are here to improve the project.
- Keep discussions technical and grounded in evidence.
- Respect privacy. Do not post private RFPs, customer documents, secrets, or credentials.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Publishing private information without permission.
- Posting secrets, exploit details, or customer data in public issues.
- Repeated low-effort disruption after maintainers ask for a change in behavior.

## Enforcement

Maintainers may edit, hide, lock, or remove comments and issues that violate this code. Maintainers may also block accounts from participating in the project when needed to protect contributors or users.

For security issues, follow `SECURITY.md` instead of opening a public issue.
