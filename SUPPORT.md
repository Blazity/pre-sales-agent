# Support

This project is an open-source starter, not a hosted service.

## Use Public Issues For

- Reproducible bugs.
- Documentation gaps.
- Setup problems with the starter.
- Feature requests that would improve the generic OSS project.

## Do Not Post

- API keys, OAuth credentials, Slack tokens, or Vercel tokens.
- Private RFPs, customer documents, commercial proposals, or Drive folder IDs.
- Full logs that include request payloads or generated client content.

## Security Reports

Report vulnerabilities privately through the process in `SECURITY.md`.

## Commercial Help

For production implementation, customization, or managed delivery, contact Blazity through the public channels listed on the Blazity organization profile.
